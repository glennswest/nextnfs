## 2. Specs

- NFSv4 WG: `draft-ietf-nfsv4-rfc8881bis` (NFSv4.1 revision) is active, -08 posted 2026-06-12; it will supersede RFC 8881 and may change clarifications nextnfs's 4.1 session code follows. No behaviour change needed now. [datatracker](https://datatracker.ietf.org/wg/nfsv4/documents/)
- `draft-ietf-nfsv4-acls-update`, `draft-ietf-nfsv4-posix-acls` (WG documents), `uncacheable-files`/`uncacheable-directories` (WGLC), internationalization draft (with IESG), Flex Files v2 (IESG milestone Nov 2026): all NFSv4.2-level; nextnfs rejects minor version 2, so none applies yet.
- RPC-over-RDMA: only `draft-ietf-nfsv4-rpcrdma-version-two-07`, expired, milestone deleted in 2022. Relevant to #107/#110: the stable target remains RPC-over-RDMA v1 (RFC 8166) — a version-2 transport should not be built on.
- No new RFC or errata found for RPCSEC_GSS (RFC 2203/5403), RPC-with-TLS (RFC 9289) or NFSv4.0 (RFC 7530) in this window.
